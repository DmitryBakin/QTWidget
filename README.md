# Пример 2.8 - «Счетчик»

Описание программы
Имеется кнопка «+1» и два поля-счетчика (на основе QLineEdit).

При нажатии «+1» первый счетчик увеличивается на 1.

Каждый раз, когда значение первого счетчика становится кратным 5, генерируется пользовательский сигнал tick_signal(), который увеличивает второй счетчик на 1.

Кнопка «Выход» завершает приложение.

В mainwindow.cpp динамически создаются edit1 и edit2 и добавляются в горизонтальный layout внутри контейнера widgetCounters.
