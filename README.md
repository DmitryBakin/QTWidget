# Пример 2.7 - «Возведение в квадрат»

### Описание программы

Пользователь вводит число в текстовое поле. При нажатии клавиши Enter вычисляется квадрат числа. Результат отображается в отдельном поле. Кнопка «Следующее» подготавливает интерфейс для нового ввода. Кнопка «Выход» закрывает приложение.

В данном задании был реализован свой валидатор — класс StrValidator, унаследованный от QValidator. Валидатор предназначен для контроля вводимых пользователем данных в реальном времени — ещё до того, как данные попадут в слот обработки (calc()).
